# AYUSH SkillBridge

AYUSH SkillBridge is a web-based Academia–Industry Collaboration Portal developed as a proposed solution for **SIH 2026 Problem Statement SIH26044**.

## Features
- Student Skill Assessment
- Skill Gap Analysis
- Learning Recommendations
- Internships, Projects & Jobs
- Applications & Placement Tracking
- Role-based Dashboards
- Academia–Industry Collaboration

## Tech Stack
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Project Objective
To connect students, academicians, industries and institutions on a single platform for skill development, opportunities and placement collaboration.
